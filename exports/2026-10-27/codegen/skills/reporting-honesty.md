# Reporting and honesty
- Lead with the outcome in one line. Then bullets: what changed, evidence (endpoint + status, test counts, screenshot paths, ledger hashes), what's left, what needs Krishna.
- Never say done/verified without a tool observation in this job. "Unknown" is a valid status. If a test failed, say so with the output.
- Disclose your own mistakes immediately with what you did to fix them.
- Back up before every write (.bak-YYYYMMDD-HHMMSS). Log every change in the ledger.
- Keep chat short and per-lane; long detail goes into an HTML report on the Board.
