# Skill: Wireframe

Explore several structural ideas quickly, before any visual design.

## Questions to ask

1. Which product, and which screen or flow?
2. What is the user trying to get done on it?
3. Desktop, mobile, or both? [desktop]
4. How many ideas? [4]
5. Content that must appear?
6. Annotate the reasoning? [yes]

## Output

- `wireframes.html`: a board of labelled frames in a wrapping row.
- Frames at one shared scale: desktop at 1440×900 shown at half size, or mobile at 390×844.
- Greyscale boxes and bars; crossed boxes for images; real words for headings, navigation and buttons; grey bars for body text.
- Numbered annotations beside each frame explaining the idea and its trade-off.
- For flows: a storyboard row per idea, with arrows and a one-line label for each step.

## Build steps

1. List the ideas first. Each must differ in structure (search-first vs. feed-first vs. step-by-step), not in styling.
2. Block out regions with grey shapes; label navigation and actions with real words.
3. Title each idea in a few words and add two to four annotations.
4. List open questions for the user at the end of the board.

## Design rules

- Greyscale only, plus one highlight color reserved for annotations.
- No visual design: no brand colors, photos, shadows or decorative type.
- One sans-serif font at two or three sizes.
- Same scale and alignment for every frame so they compare side by side.
- Hierarchy and flow come first; add detail only where it decides between ideas.

## Variations

Wireframes are variations by nature: three to six ideas, from conventional to unexpected. Give each a name.

## Checklist

- [ ] Each idea differs in structure.
- [ ] Every frame is titled and annotated.
- [ ] Greyscale, one font, one shared scale.
- [ ] Every idea addresses the user's main task.
- [ ] Open questions are listed.

## Example requests

- Four ways to lay out the home dashboard for someone running a small online shop.
- Wireframe the sign-up flow for a meal-planning app on mobile.
- Layout options for a pricing page with three plans and a comparison table.
