The sequence · each phase has one gate that must move before the next

1

Eval harness first

You can't improve what you don't measure. Build golden sets per task-type (codegen, structured-reasoning, graph-synth) and a one-command scorer. Every score becomes a real number, dated, reproducible — no more claimed percentages.

GATE ▸ gap-scorecard.json exists & reproduces a baseline number
2

Wire real rewards

Hebbian + Q-table are cosmetic until the reward is real. Wire test-pass / watch-time / revenue / user-accept as the signal. Now plasticity learns from outcomes, not noise.

GATE ▸ Q-table converges on a real reward; shown on a chart
3

Fix quality at the model (DSPy ladder)

The biggest ROI on the board. Climb the ladder — structure → MIPROv2 → graph grounding → GEPA/finetune — against the Phase-1 metric. This is where the gap-to-Fable number actually drops. (Driven by the ai-discovery-research skill just pushed.)

GATE ▸ measured +N points on the golden set vs baseline
4

Prove one autonomous loop end-to-end

One real loop, zero human touch, measured: codegen ships a validated PR on its own, OR the router self-tunes its cascade from live cost/latency. Autonomy stops being "wired" and becomes "demonstrated."

GATE ▸ one loop runs N cycles zero-touch at acceptable quality
5

Consolidate the spine

One shared router + graph + tester spine, not per-app reimplementations. The frozen apps adopt it later for free. Depth compounds; sprawl divides.

GATE ▸ both focus apps run on one spine; dup code deleted
