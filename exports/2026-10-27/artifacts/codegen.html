Structured Reasoning

One output contract for every model call — a single JSON object the parser can't fail on (fenced, balanced-scan, clamped). It's what makes the agent composable: thinking, the answer, an optional tool call, and the model's own confidence.

StructuredThought — the contract

answerfinal answer

confidence0.0–1.0 (clamped)

Why one field. A single structured output means one parser, one contract, and a confidence the router and the loop can act on — instead of scraping free text.

Self-Improvement

Because its own code is in its graph, codegen can code better on tasks about itself — and it's measured, not claimed. The baseline steps up only when a change is proven on the eval harness; the live line jitters per task. A self-rewrite that only "passes because nothing broke" never moves it.
