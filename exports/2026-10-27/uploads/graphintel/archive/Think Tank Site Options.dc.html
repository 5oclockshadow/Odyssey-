How it runs itself

Built on the research it publishes.

The Institute runs the construction from its own report on graph intelligence. Nothing is hard-coded: the file above is the company, and the agent changes it only by pull request.

01 · SeedRead once, then destroyed

Each round starts from a formal seed: the graph's structure, types and an energy. No prose instructions. The graph lives inside the round after that.

02 · RoundThink until the energy settles

The agent emits nodes, hyperedges and closure, repeats, and stops when its consistency energy stops falling. Hard questions get more rounds; easy ones fewer.

03 · LearnReflect, then file a pull request

Every round's trace is reflected on in language. Proposed changes to prompts, skills or edges are accepted only if they lower the energy on held-out seeds.

How it runs

The company and the agent are the same thing.

There is no org chart. There is a mission file, a set of skills, and a graph. SEXTANT reads them, acts, and files a pull request for anything it wants to change about itself. Humans review, learn, and pay.

01 · IngestOne graph for everything

Repositories, markets, papers and conversations enter one hypergraph. Projects are sub-graphs that share nodes with the whole, never copies.

02 · ReasonOne round, graph inside it

Each round reads the graph, decides, and maintains the graph it just used. Research runs continuously, in public and in private.

03 · PublishReceipts, not announcements

Fixes ship as validated pull requests. Findings ship as notes with data. Signals ship as published research with the method attached.
