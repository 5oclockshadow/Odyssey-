## Round 1 findings

### Zep / Graphiti (Rasmussen et al., Jan 2025) arXiv 2501.13956
- Memory = temporally-aware dynamic KG G=(N,E,φ), φ: E→N×N incidence fn; 3 tiers: episode, semantic entity, community subgraphs. Bi-temporal.
- DMR: 94.8% vs MemGPT 93.4%. LongMemEval: up to +18.5% accuracy, ~90% latency reduction vs full-context baseline (conversations ~115k tokens). Experiments Dec 2024–Jan 2025.
- Exception: single-session-assistant questions dropped 17.7% (gpt-4o) / 9.06% (gpt-4o-mini).
- Graphiti OSS 20k+ stars (Zep site, May 2026). https://arxiv.org/abs/2501.13956 ; https://www.getzep.com/ai-agents/temporal-knowledge-graph/

### HippoRAG 2 (Gutiérrez et al., ICML 2025) arXiv 2502.14802
- KG from LLM-extracted triples + Personalized PageRank; deeper passage integration; recognition-memory triple filter (DSPy MIPROv2).
- +7% on associative memory tasks over SOTA embedding model (NV-Embed-v2), also better on factual & sense-making. Prior KG-RAG methods "drop considerably below standard RAG" on basic factual recall — HippoRAG 2 fixes this.
- HippoRAG v1: NeurIPS'24. Code: https://github.com/OSU-NLP-Group/HippoRAG ; https://arxiv.org/abs/2502.14802

### Mem0 (Chhikara et al., ECAI 2025) arXiv 2504.19413
- Paper: 26% relative improvement (LLM-as-judge) over OpenAI memory on LoCoMo; graph-memory variant ~2% higher than base; 91% lower p95 latency; >90% token savings vs full-context.
- 2026 algorithm (Apr 2026): LoCoMo 92.5, LongMemEval 94.4, BEAM 64.1; ~6,956 tokens/retrieval vs ~26,000 full context; biggest gains temporal (+29.3) and multi-hop (+25.2). Caveat from Mem0 itself: small benchmarks can be gamed by bigger context/frontier models. https://mem0.ai/research ; https://mem0.ai/blog/state-of-ai-agent-memory-2026 ; https://huggingface.co/papers/2504.19413
- Independent 2026 papers show Mem0 underperforming on other benchmarks (MemConflict: Mem0 36.12 macro vs HiGram 67.84; arXiv 2608.05095) — benchmark disagreement is real.

### GraphRAG-Bench / "When to use Graphs in RAG" (Xiang et al., ICLR 2026) arXiv 2506.05690
- "GraphRAG frequently underperforms vanilla RAG on many real-world tasks." Basic RAG comparable or better on simple fact retrieval; GraphRAG helps on complex multi-hop reasoning, large-scale/dense corpora; "token tax". Follow-up LinearRAG (2510.10114): graph recall gains offset by noisy/ambiguous context. https://arxiv.org/abs/2506.05690 ; https://github.com/GraphRAG-Bench/GraphRAG-Benchmark

### GPTSwarm (Zhuge et al., ICML 2024) arXiv 2402.16823
- LLM agents described as computational graphs: nodes = functions/LLM queries, edges = information flow; recursively composable into swarms. Node optimization (prompts) + edge optimization (connectivity via REINFORCE). pip install gptswarm. https://proceedings.mlr.press/v235/zhuge24a.html ; https://github.com/metauto-ai/GPTSwarm
- Related: AFlow (MCTS over workflow graphs, 2410.10762); G-Designer (GNN designs multi-agent topologies, ICML 2025); "From Agent Loops to Structured Graphs" (arXiv 2604.11378, 2026) notes LangGraph is most widely adopted graph agent framework; AGORA finds simple CoT often robust with less overhead than graph approaches.

### Transformers are GNNs (Joshi, arXiv 2506.22084, Jun 2025; blog 2020)
- Transformers = message-passing GNNs on fully connected token graph; attention = learned relative importance; positional encodings = structure hints; "GNNs currently winning the hardware lottery" (dense matmul vs sparse message passing). https://arxiv.org/abs/2506.22084
- 2026 follow-on: "On the Runway Cascade of Transformers" (2601.14522) uses GNN over-squashing/bottleneck theory to explain lost-in-the-middle, attention sinks. "Transformers Can Learn Connectivity in Some Graphs but Not Others" (2509.22343). "Towards Mechanistic Interpretability of Graph Transformers via Attention Graphs" (2502.12352).

### AlphaProof (Hubert et al., Nature, Nov 2025) s41586-025-09833-y
- AlphaZero-inspired RL agent in Lean; 3B-param encoder-decoder; encoder takes pretty-printed Lean tactic state → latent representation → policy/value heads; trained on ~300B tokens code/math, 300k human Lean proofs, then ~80M auto-formalized problems; test-time RL on problem variants.
- IMO 2024: solved P1, P2, P6 (AlphaGeometry 2 solved P4); 28/42 points, silver (1 below gold). Needs humans to formalize the statements; proofs "barely comprehensible" to humans (Shape of Math to Come, 2510.15924). https://www.nature.com/articles/s41586-025-09833-y

## Round 2 findings (verified)

### ALPINE (Wang et al., NeurIPS 2024) arXiv 2405.09220 — Microsoft Research
- Planning abstracted as path-finding source→target. Transformer can execute path-finding by embedding adjacency + reachability matrices in weights; gradient dynamics learn adjacency (in W^M) and only the *observed* reachability (in W^V). Limitation: cannot infer reachability by transitivity → fails when path concatenation is needed. Consistent on Blocksworld.

### Belief state geometry (Shai et al., NeurIPS 2024) arXiv 2405.15943
- Transformers trained on HMM outputs (Mess3, 3 hidden states, vocab {A,B,C}) linearly represent the belief-state simplex geometry in the residual stream — fractal structure recovered by linear regression from 64-d activations to 3-d belief distributions; emerges over training; shuffled control collapses to centroid. RRXOR process: 36 belief states, 4-simplex, spread across layers; distances correlate R²≈0.95. Belief states contain information about the entire future beyond next token.

### Transformers Struggle to Learn to Search (Saparov et al., ICLR 2025) arXiv 2412.04703
- Graph connectivity testbed; with right training distribution small transformers learn to search; learned algorithm = exponential path-merging: each vertex embedding stores the set of reachable vertices, each layer expands sets → can search vertices exponential in #layers. But difficulty grows with graph size; not resolved by scale; CoT does not fix it on larger graphs.
- Follow-ups: "Transformers Can Learn Connectivity in Some Graphs but Not Others" (2509.22343): grid-graph dimensionality predicts learnability; scale helps on grids; many disconnected components → struggle. "Transformers Provably Learn Algorithmic Solutions for Graph Connectivity, But Only with the Right Data" (2510.19753).

### Energy-Based Transformers (Gladstone et al., ICLR 2026 oral) arXiv 2507.02092
- Assign energy to (input, candidate prediction); predict by gradient-descent energy minimization. Scale up to 35% faster than Transformer++ w.r.t. data, batch, params, FLOPs, depth; System-2 thinking improves inference by up to 29% on language; 99% fewer forward passes than DiT on denoising; gains larger further OOD. Authors concede some scaling numbers (2.92%) marginal.

### HELM (He et al., NeurIPS 2025) arXiv 2505.24722
- First fully hyperbolic LLMs at billion-param scale; Mixture-of-Curvature Experts (HELM-MiCE), hyperbolic MLA, hyperbolic RoPE + RMSNorm; up to 4% gains over LLaMA/DeepSeek-style Euclidean baselines on MMLU/ARC. Related: HypLoRA; "Position: Beyond Euclidean" (2504.08896); HyperCore framework (2504.08912).

### HyperGraphRAG (Luo et al., NeurIPS 2025) arXiv 2503.21322
- Hyperedges = n-ary facts (n≥2), each with NL description; stored as bipartite graph DB + separate vector DBs for entities and hyperedges; outperforms standard RAG and graph RAG across medicine/agriculture/CS/law. Code github.com/LHRLAB/HyperGraphRAG.
- HyperRAG (2602.14470, 2026): n-ary hypergraphs "preserve high-order relational integrity, enabling shallower inference"; HyperRetriever +2.95% MRR, +1.23% Hits@10 over strongest baseline on WikiTopics + HotpotQA/MuSiQue/2Wiki.

### Neural Sheaf Diffusion (Bodnar et al., NeurIPS 2022) arXiv 2202.04579
- Cellular sheaves assign vector spaces to nodes/edges and linear restriction maps; GNNs implicitly assume the trivial sheaf; sheaf Laplacian generalizes graph Laplacian (GCN = Euler step of heat diffusion: σ((I−Δ0)XW)). Non-trivial sheaf gives control over asymptotic behaviour → avoids oversmoothing, handles heterophily; sheaf learned from data; new Cheeger inequality for sheaf Laplacian spectral gap. Predecessor: Hansen & Gebhart 2020 (2012.06333). 2025 follow-up: Polynomial Neural Sheaf Diffusion (2512.00242).

## Round 3 findings (verified)

### Coconut (Hao et al., FAIR Meta, Dec 2024; updated Nov 2025) arXiv 2412.06769
- Last hidden state fed back as next input embedding ("continuous thought") instead of decoding to a token. On ProsQA (DAGs, find valid reasoning path) continuous thoughts encode multiple alternative next steps → BFS-like search with implicit value function; outperforms CoT on tasks needing search/backtracking with fewer tokens; multi-stage curriculum essential (without it, no better than direct answer). GPT-2 scale. Code github.com/facebookresearch/coconut.

### Anthropic circuit tracing (Mar 2025 research; open-sourced May 30, 2025)
- Attribution graphs: replacement model with cross-layer transcoder features; graph = pruned flow of influence between interpretable features → output. Library github.com/safety-research/circuit-tracer (Hanna et al.); Neuronpedia frontend; supports Gemma-2-2b, Llama-3.2-1b. Used to study multi-step reasoning ("capital of the state containing Dallas"). 2026 follow-ons: CLT-Forge (2603.21014), WASD (2603.18474), VLM circuit tracing (2602.20330).

### Talk like a Graph (Fatemi, Halcrow, Perozzi; ICLR 2024) arXiv 2310.04560
- Encoding graphs as text: LLMs perform poorly on basic graph tasks (below majority baseline on edge existence 53.96% / cycle check 81.96%); encoder choice swings accuracy 4.8%–61.8% depending on task; performance depends on graph structure (ER vs others); bigger PaLM 2 better. GraphQA benchmark. github.com/google-research/talk-like-a-graph. GraphToken (2402.05862) = learned structure encoder → soft tokens.

### Categorical Deep Learning (Gavranović, Lessard, Dudzik, von Glehn, Araújo, Veličković; ICML 2024) arXiv 2402.15332
- Neural nets f: A→B as monad-algebra homomorphisms between algebras (A,a),(B,b) for monad (M,η,μ); GDL recovered with group-action monad M(X)=G×X; also recovers RNNs, automata constructs. Survey 2410.05353 says field too young to know. 2025: "Categorical Construction of Logically Verifiable Neural Architectures" (2508.11647): Lawvere theories → free-algebra monads; logical constraints unify with geometric ones under monad algebras.

### Othello-GPT (Li et al., ICLR 2023, 2210.13382) + Nanda et al. 2023 (2309.00941)
- GPT trained only on legal move sequences, no rules given; nonlinear probes recover board state; interventions causal. Nanda: representation is LINEAR when framed as mine/theirs (not black/white), controllable via vector arithmetic; linear probe near-unity accuracy in deeper layers (Hazineh et al. 2310.07582: even 1-layer model).

### TDL position (Papamarkou et al., ICML 2024) arXiv 2402.08871; TopoX (2402.02441); CCNNs (Hajij et al. 2206.00606)
- Combinatorial complexes: no constraint on relation set (like hypergraphs) + hierarchical ranks (like cell complexes); message passing across ranks. Software: TopoNetX/TopoEmbedX/TopoModelX, TopoBench (2406.06642), DHG (graphs+hypergraphs), HyperNetX, XGI. ICML 2024 TDL challenge: 52 valid submissions, 31 teams.

### Vafa et al. (NeurIPS 2024) arXiv 2406.03689 — counter-evidence
- Transformers trained on NYC taxi turn-by-turn sequences find valid and usually shortest routes, yet Myhill-Nerode-inspired metrics show incoherent world model: reconstructed street map "bears little resemblance" to real one (impossible orientations, flyovers); route planning breaks under detours. Rebuttal-style 2026 paper "World Modeling in Transformers" (2609.21748): behavior underdetermines mechanism — could be a coherent map with misfiring localization. Follow-up: Vafa et al. 2025 inductive-bias probe (2507.06952); 2026 multi-token prediction improves consistency (2604.06155).

## Round 6 — v3 (Oct 1 2026): output fields, nesting, attributes; runtime ontology with seeded core
- Tam et al. "Let Me Speak Freely?" EMNLP 2024 (2408.02442): stricter format → more reasoning degradation; JSON-mode worst, then FRI, NL-to-format, NL; JSON-mode *better* on classification; cause partly key order (answer before reason); 2-field schema in study; NL-to-format recovers.
- Capacity, Not Format (2606.09410): penalty = premature serialization; recovers whenever unconstrained reasoning precedes structured submission; moderated by capacity margin.
- Field-order replications: dsdev.in (reasoning-first vs answer-first, JSON mode): GSM8K 94.2 vs 31.8; Last Letter 91.3 vs 6.0; Shuffled Obj 79.7 vs 14.2; second GSM8K run 95.75 vs 53.75. Castillo: 46.67% vs 33.33%. Mechanism: constrained decoders emit keys in declaration order (2^k FSM states otherwise); forced key tokens act as prompt; required non-nullable fields manufacture values.
- JSONSchemaBench (Geng et al. 2501.10868; 9,558 schemas; Guidance/Outlines/llama.cpp/XGrammar/OpenAI/Gemini): coverage >86% simple → GitHub-Hard: Guidance 41%, llama.cpp 39%, XGrammar 28%, Outlines 3%, OpenAI 9%, Gemini none at medium+; constrained decoding modestly improves GSM8K accuracy (Guidance); up to 50% faster.
- ExtractBench (2602.12247): 369-field SEC schema → 0% validity all models both modes; structured-output APIs reduced validity 51%→37%, best pass rate 6.9%→5.5%; GPT-5 credit agreements 86.9%→70.0% under constrained decoding ("grammar state across thousands of tokens competes with attention to content").
- TOON vs JSON (2603.03306): constraints as guardrail for weak models (Qwen2.5-Coder-7B 0%→75%, 37.7k→4.4k tokens) but Hermes-4-405B 92.5%→35.0% under strict grammar.
- He et al. 2411.10541: prompt template moves GPT-3.5 up to 40% (code translation); GPT-4 more robust.
- Field attributes: hybrid LLM+SLM paper (2609.16091) same gpt-4o-mini: named params + declared types 0.98 tool-call accuracy vs 0.38 exact-match with generic schema. Gorilla: doc precision ↔ invocation accuracy.
- Runtime ontology precedents: EDC (Zhang & Soh EMNLP 2024, 2404.03868): open extraction → define → canonicalize; self-generated schema when none given. Graphiti: "prescribed & learned ontology" (Pydantic types = prescribed; else emerge); Zep strict_ontology toggle; each node one type; set ontology before ingestion (not re-extracted). AutoSchemaKG already in notes.
- DSPy: Khattab et al. 2310.03714; ChainOfThought prepends `reasoning` field = free text first.

### Challenges found
- **GEPA** (Agrawal et al., ICLR 2026 **oral**, 2507.19457): reflective prompt evolution; beats GRPO by 6pp avg / up to 20% with **35× fewer rollouts**; beats MIPROv2 by >10pp (+12pp AIME-2025); works as inference-time search for code opt. Reflects on *trajectories* (reasoning, tool calls, tool outputs) — i.e. exactly what the user's Phoenix/Arize `finally` already logs. Verdict: user is one step from GEPA and doesn't take it; Q-tabling is a weaker scalar-reward learner than language reflection.
- **Context Rot** (Chroma, Hong/Troynikov/Huber 2025): 18 frontier models, all degrade non-uniformly with input length, 30–50% drops well before the limit; semantic-similarity of distractors drives decay more than length; **coherent, well-structured input degrades attention MORE than shuffled**. Plus lost-in-the-middle U-curve (Liu et al., TACL 2024). Direct hit on one Signature emitting 6-deep nested output with six thought maps in one round.
- **Counter-evidence FOR the single round**: Microsoft/Salesforce result (reported in Breunig's context-rot taxonomy, see 2603.09619): **39% quality drop when a single prompt is split into sequential turns** — early incomplete attempts poison the context. So single-shot is defensible; the problem is nesting depth, not single-shot.
- **MaAS agentic supernet** (Zhang et al., ICML 2025, 2502.04180): optimizes a probabilistic *distribution* of architectures, samples query-dependent architecture at inference; **6–45% of the inference cost** of handcrafted/automated MAS, **+0.54–16.89%** performance, transfers across datasets and backbones. Direct challenge: a fixed sole-Signature cannot allocate per-query compute.
- **G-Designer** (2410.11782): VGAE designs task-adaptive communication topology; best on 5/6 benchmarks; +4.0% pass@1 over MetaGPT on HumanEval; beats GPTSwarm/DyLAN by 0.20–1.41%. **ARG-Designer** (Li et al. 2026): autoregressive graph generation — generates topology from scratch node-by-node, v_i ~ P(v_i | G_<i, q, R), END token terminates. That is literally runtime-determined topology, already published.
- **AutoSchemaKG / ATLAS** (Bai, Fan, Song; **ACL 2026**, 2505.23628): fully autonomous KG construction, **no predefined schema**; induces schema + triples simultaneously; entity/event/concept conceptualization; 50M docs → 900M+ nodes, 5.9B edges; **95% semantic alignment with human-crafted schemas, zero manual intervention**. Direct challenge to mission.yaml holding the ontology. Published limitation (2608.13384): LLM-heavy, economically prohibitive at scale, and **one-time batch-style synthesis** — which is precisely where a runtime incremental postact loop could win.
- **Self-evolving agents**: Gödel Agent (Yin et al. 2025) monkey-patches its own code, full evolution ≈ **$15** vs Meta Agent Search $300; on Game of 24 spontaneously switches from LLM methods to search, 100%. **DGM** (Zhang et al., ICLR 2026, 2505.22954): archive of self-modified coding agents, 80 iterations, staged eval 10→50→200 tasks, beats both no-self-improve and no-open-ended baselines, features transfer across LLMs. **Huxley-Gödel Machine** (clade metaproductivity). **Live-SWE-Agent** (Xia et al. 2025): first agent that evolves its own scaffolding/tools **at runtime**. Direct challenge to "parking lot: back up before every permanent edit" — industry has archives and clade metrics, not backups.
- **PACE** (2606.08106): anytime-valid acceptance tests for self-evolving agents; notes all prior systems select modifications by empirical score and **flag objective hacking + stability of self-modification as open problems**; none treat acceptance as a statistical decision. This is the missing piece in the user's edit loop.
- **A-MEM** (Xu et al. 2025, 2502.12110): Zettelkasten agentic memory — LLM decides linking and *evolution* of existing notes at write time; dynamically evolving semantic graph; reported 2×–6× multi-hop efficiency improvements with token savings; DialSim F1 3.45 vs MemGPT 1.18. Nemori (2508.03341, predict-calibrate episodic segmentation), G-Memory (2506.07398), MAGMA (2601.03236, multi-graph; A-MEM overall 0.580 in its table), GAM (2604.12285). Verdict: "graph self-maintenance in the postact map" is **not novel in itself** — A-MEM already does write-time autonomous graph evolution. Novelty must be the *same-round* coupling + read-once seed.
- **HRM** (Wang et al. 2025, 2506.21734): 27M params, 40.3% ARC-AGI-1. **TRM** (Jolicoeur-Martineau, 2510.04871, ARC Prize 2025 1st-place paper award): 7M params, single network, separate answer y and latent z, N_sup=16 deep-supervised refinement steps: **z ← f(x,y,z)** n times (recursive reasoning) then **y ← g(y,z)**; **45% ARC-AGI-1, 8% ARC-AGI-2** (Gemini 2.5 Pro 4.9% with high TTC). ARC Prize independent analysis: **deep supervision is the primary driver (19%→39%)**, recursive hierarchy only slightly better than a regular model. THIS IS THE KEY CHALLENGE: the user's reasoning→preact→act→postact map loop is TRM's loop written in tokens; TRM does it in latent space at 7M params and wins where LLMs fail. Known gap: TRM/HRM "lack the ability to understand natural language" (2608.08113).
- **ReLIT** (2608.08113): frozen foundation model + trainable Recursive Reasoning Block, three interacting vector states — the bridge between TRM's latent recursion and LLM semantics. Best published template for "the graph lives in the round".
- Also: AFlow (2410.10762) MCTS over workflow graphs; Meta-Harness (end-to-end harness optimization); MemGen (2509.24704, generative latent memory); CAM (NeurIPS 2026); LeanRAG (2508.10391); Graph-based agent memory survey (2602.05665); LLM-empowered KG construction survey (2510.20345).

### Verdict logic for v2
Subsystem-by-subsystem, something published already matches or beats each piece: optimizer → GEPA; topology → MaAS/ARG-Designer; ontology → AutoSchemaKG; self-maintaining memory graph → A-MEM/Zep; runtime self-evolution → Live-SWE-Agent/DGM; acceptance of self-edits → PACE; latent iterative reasoning → TRM/HRM/ReLIT. What is NOT published: (a) read-once-then-destroyed formal seed, (b) ontology + topology maintained by the *same* inference round that consumed them (one-round isomorphism), (c) hypergraph-arity thought map with an explicit consistency energy as the stopping rule. That intersection is the paper.
