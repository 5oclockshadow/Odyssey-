The Threshold Institute/the stack · v0.2.0/2 October 2026

Everything, and where it runs.

Four containers on the top layer: the site and the agent, each with its own docker. Everything else the agent depends on (Phoenix, Redis, the MCP hub, every sandbox run) it starts inside its own docker. The agent is the company: one Signature, one graph, and every span, log line, incident and shipped app is written into that same graph, so when something breaks the graph already knows where. Your day is a terminal.

Run it

cp .env.example .env     # model key · OWNER_PASSWORD · SESSION_SECRET
docker compose up -d     # web + agent, each with its own docker-in-docker
open http://localhost/terminal      # sign in; your day
open http://localhost:6006          # Phoenix: every span of every round

# without docker (no sandbox, no apps, no Phoenix)
cd apps/engine && pip install -r requirements.txt
pytest -q                           # 41 tests, no model, no network
uvicorn serve:app --port 8000
