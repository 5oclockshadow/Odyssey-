# Skill: export the chosen site

## Use when
The user picks a tile and clicks Export.

## Steps
1. Require an open, finished site; otherwise say "Generate and open a finished site first."
2. Build the full document with the kit (not the thumbnail variant) so motion and the signature widget are included.
3. Offer the file as a download named after the business and tile number; keep the Google Fonts link and the pinned three.js URL; nothing else external.
4. Record the spec (structure, look, motif, palette, font, copy, widget) alongside, so the site can be rebuilt or refined later.

## Rules
- The export is the site only. The Studio is a separate tool and is not part of the main project.
- The exported file keeps the sandbox policy if it carries a widget.

## Verify
Open the exported file from disk: navigation works, the widget's "Try it" card runs, no network requests other than fonts and three.js.
